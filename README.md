# IoT-Based-Smart-Floodwater-Monitoring-Using-ESP8266-and-KiwisIoT
IoT-Based Smart Floodwater Monitoring using NodeMCU ESP8266 and a water level sensor with real-time flood monitoring and data visualization through the KiwisIoT platform.
IoT-Based Smart Floodwater Monitoring Using ESP8266 and KiwisIoT
About the Project
The IoT-Based Smart Floodwater Monitoring System is an IoT project designed to monitor rising water levels and identify potential flood conditions in real time.

Using a NodeMCU ESP8266 microcontroller and a water level sensor, the system continuously measures water levels and transmits the collected data to the KiwisIoT platform through Wi-Fi. Users can remotely monitor water levels through an online dashboard and observe changes that may indicate potential flooding.

By integrating KiwisIoT, this project demonstrates an effective approach to real-time flood monitoring, water level tracking, and IoT-based environmental monitoring.
